# Fixer's Cut ローグライク版

ヨミハマの新人フィクサーとして、1回30〜45分の「12夜のラン」を何度も遊ぶブラウザーゲームです。キャンペーン版 Fixer's Cut（`tsuonosuke-bot/Cyberpunk` の `campaign-v1`、コミット `b3248ea`）を複製し、企画書 `docs/roguelike-plan.pdf` に沿って作り替えています。外部サーバーやビルドは不要です。UTF-8の静的HTTPサーバーで `index.html` を開いてください。保存先はブラウザーのlocalStorageです。

## ローグライク版の仕様（段取り1〜4：地区マップ・終わり方・報酬3択・義体の枠・前歴・幕のボス・サイバーサイコシス）

- 1ランは3幕・12夜（第1幕 屋台街／第2幕 港湾倉庫／第3幕 企業区画上層）。依頼のランクと敵の基準値は幕と同じ。
- 毎夜、地区マップから行き先を1つ選ぶ。決めたら取り消せない。行き先を決めるまで夜は明かせない。各幕は4夜で、1〜3夜目の行き先は3・3・2つ、4夜目は大仕事。幕の4夜はすべて見える。
  - 依頼：その幕と同じランクの依頼1件。危ない依頼：1つ上のランク（第3幕はランク3のDV+2、報酬1.3倍）。第1幕には出ない。
  - 闇医者・古物屋・路地裏：その夜だけ画面が開く。路地裏の候補は、隊にいないロールが先に並ぶ。
  - 隠れ家：全員のHPが戻り、人間性+5。事件：選択肢つきの出来事（白蛇会の訪問・情報屋・倒れていたランナー・記者）。
  - 行き先の重みと夜ごとの縛りは企画書どおり（1夜目は依頼、2夜目は依頼と闇医者か古物屋、3夜目は隠れ家か闇医者を必ず含む）。第1幕の大仕事にはネットランナーが要るので、第1幕の1夜目には路地裏を必ず出す。3夜目の依頼は1夜で終わるものだけ。
- 2夜依頼は次の夜も使う（その夜は行き先を選べない）。大仕事が2夜のときの2夜目は、幕の夜数に数えない。
- 大仕事（`RUN_JOBS`）：第1幕は電気屋から箱の鍵を取り返す、第2幕は組んだ社の手引きで名簿を奪う（社ごとに3通り）、第3幕は箱を開ける（社ごとに3通り）。どれも1夜。失敗（送り出さずに夜を明かした場合も含む）したら、次の夜に一度だけ挑み直せる（幕の夜数に数えない）。2度目も失敗するとランは終わる。第1幕を越えると組む社を選び、第3幕を越えると箱の行き先（結末）を選ぶ。
- 幕のボス（`RUN_BOSSES`）：大仕事に1体ずつ立つ。強さはその幕の敵の基準値+2。名前・耐久・護衛は地区マップと依頼の画面ではじめから見え、仕掛けと攻略の道は情報を買うと見える。ボスが倒れると護衛は散る。撤退して挑み直すとき、削った耐久は戻らない（護衛は戻る）。倒すと、その大仕事の報酬にボスの品が1つ混ざる（電気屋のデッキ・カナメの狙撃用義眼。古物屋と闇医者では売らない）。
  - 第1幕「電気屋」（耐久2）：店の奥に隠れていて、知覚DV17で見つけないと現場から撃てない。ネット担当がインターフェースで2回成功すると倒れる。毎ラウンド、ネット担当にICE攻撃。白蛇会との関係+30以上なら、説得DV15で1,000crの取引に変えられる。
  - 第2幕「カナメ」（耐久3）：ソロ型の傭兵ランナー。1ラウンドに2回撃つ。護衛は狙撃手と群れ。2ラウンドで倒しきれないと目標を1つ持ち去り、次の逃走が追撃戦になる。追手を退けて運転に成功すれば取り返せる。
  - 第3幕（組んだ社で変わる）：ミツカネ「鋼の番犬」（耐久4、テックか徹甲ライフルがないと1発で1しか削れない。指揮官ナカガワが生きているあいだ、ほかの敵の攻撃+1、知覚DV18で見抜けば先に狙える）。ヴェルデ「被検体」（耐久3、戦闘薬で攻撃+2。説得DV18で正気に戻せば撃たずに終わり、結果画面の一行が変わる）。ハクロウ「保守主任」（ネットのボス。黒ICE3層DV18・19・20、失敗ごとに逆流2d6。抜けなければ現場から電子DV20で回線を切る、3回まで）。
- 前歴（ランの始めに選ぶ）：最初の隊（資質なし）と、ラン中ずっと効く利点と弱み。元ソロ（ジロウとサエ。交戦の1ラウンド目に射撃+1）、元ネットランナー（ネットランナー・テック。各幕のはじめに情報券+1）、闇医者のツテ（メドテック・ソロ。義体の人間性コスト−1、最低1）、企業の元社員（テック・ドライバー。組む社を始めに決め、その社のヒート−15・残りは+10）、白蛇会の身内（ソロ2人。白蛇会との関係+30。路地裏の候補は義体を入れていて人間性が低いことが多い）、寄せ集め（好きなロールで3人。初期資金1,000cr、報酬は2択）。後の3つは信用で解放する予定だが、信用（段取り6）ができるまでは最初から選べる。
- ランの終わり：廃業（3夜続けて所持金がマイナス）・全滅（隊が0人）・大仕事に2度失敗・クリア。結果画面に、たどった道と到達点、これまでのラン数・クリア数を出す。ラン数と最高到達は `fixers-cut-meta-v1` に残る。
- 契約なし：ランでは歩合・専属の区別をなくした。雇った人は全員隊員で、分け前はフィクサーに入り、手当はかからず、装備や義体はフィクサーの所持金で買う。忠誠による持ち逃げ・引き抜き・自腹の買い物も起きない。
- 雇う：路地裏（夜を使う。契約金なし、候補3人、資質の出やすさ2倍）のほかに、隊の画面の「顔見せ」で毎晩2人から雇える（夜を使わない。契約金は第1幕1,500cr・第2幕3,000cr・第3幕5,000cr。隊にいないロールが先に出る）。隊員が死ぬ・引き渡す・脱走するなどで欠けると、次の報酬に補充のランナーが必ず1人入る（自分で外したときは除く）。
- お金：初期3,000cr。毎夜の固定費は隠れ家代200crだけ。借金・義体ローン・設備はなし。依頼報酬は今のまま（企画書の目安どおり）。
- 報酬3択：依頼に成功すると、crとは別に3つの候補から1つを取る（失敗・撤退では出ない）。どれも取らなければ500cr。
  - 候補の重み：義体25・装備25・ランナー15・情報券15（情報購入2回無料）・cr20（第1幕800・第2幕2,000・第3幕4,000）。同じ候補は並ばず、情報券とcrとランナーは1つまで。
  - 義体は施術費なしで、人間性は削れる。入れる人をその場で選び、そのロールに合う人（`ROLE_CYBER` に同じ系統がある人）だけが選べる。装備は持ち主を選び、前の装備は下取り。ランナーはそのまま隊員として加わる。
  - 幕ごとの上限：義体は第1幕が基本モデルだけ、第2幕がMk.IIまで、第3幕がMk.IIIまで。装備は第1幕が2,000crまで、第2幕が5,000crまで、第3幕はすべて。ランナーの資質は第2幕で1.5倍、第3幕で2倍出やすい。
  - 入っている系統の上位モデルと、隊にいないロールのランナーは3倍出やすい。取った義体と装備は、そのランでは二度と出ない（取らなかったものは戻る）。
  - 危ない依頼・2夜依頼・大仕事の後は、1つが必ず希少（上位モデル・資質つき・その幕でいちばん高い装備）。
  - 精算の画面で選ぶ。選ばずに読み込み直したときは、次に開いたときに単独で選ばせる。
- 義体の枠：神経系・頭脳・感覚と発声・腕と手・内臓が2つずつ、体表が1つ（全部で11）。同じ系統の上位モデルは入れ替わるので枠を使わない。枠がいっぱいの部位には、同じ部位のどれかを外してから入れる（報酬では「○○を外して入れる」を選ぶ。闇医者では「外す」）。外した義体は戻らず、人間性も戻らない。キャンペーン版には枠はない。
- サイバーサイコシス（ラン中だけ。交戦の始めに判定）：
  - 不安定（人間性16〜30）：d10で1が出ると動揺し、その交戦は射撃・回避−2。
  - 兆候（1〜15）：d10が (16−人間性)÷4 の切り上げ以下なら発作で暴走（12〜15で10%、1〜3で40%）。暴走中は射撃+2で1ラウンドに2回撃つ（ソロの二連射とは重ならない）。続行／撤退の判断は出ない。敵を倒すたびに標的の企業のヒート+4（テーザーでも防げない）。交戦の後に人間性−2。ラザロの対象外。通信では赤い行で出る。
  - 暴走した人が同じ依頼で3体倒すと、次の交戦の前に市警の鎮圧班が到着し、続行／撤退と同じように止まる。引き渡す（その人は拘束されてランから抜ける。依頼は続く）・かばう（鎮圧班と交戦：隊員2人、第3幕は3人、耐久2、DV・攻撃はその幕の基準値+4、4d6+4、暴走した人を先に狙う。勝てば依頼は続くが、その幕のあいだ全依頼の敵+1）・撤退する（依頼は失敗）。見積もりでは引き渡すとして数える。
  - 喪失（0）：隠れ家から消え、5夜のあいだ地区マップに「元部下」の行き先が加わる（報酬は幕×3,000cr）。行かなければ鎮圧班が片付けて慰霊碑に刻まれる。元部下との交戦で3ラウンド以内に倒しきれなかったときも、鎮圧班が割り込んで片付ける（依頼は失敗、ヒートは上がらない）。
- ラザロ：闇医者でランナーごとにプランを選ぶ。基本（100cr/夜。死亡セーブに失敗したらHP1で回収、回収費は報酬額の30%）。武装回収（第2幕から、300cr/夜。死亡セーブに失敗したか、生き延びて動けなくなったときに出動。回収班が1ラウンドだけ敵を撃ち〈腕前15＋d10〉、本人をHP半分で運び出す。出動費1,500cr＋報酬額の30%。1つの依頼で1回まで、2人目からは基本と同じ）。
- 技能の伸びは n→n+1 に n+1 回（最低2回）。セラピーは600crで、次の1夜だけ出せない。
- ヒート80以上の社が標的の依頼は、敵が1体増える。ヒート100の襲撃は今のまま。
- 保存は `fixers-cut-run-v1`（キャンペーン版の保存データとは別）。夜が明けるたびに上書きし、終わったランは続きから始められない。
- 構成：`js/run.js` が幕・地区マップ・行き先・事件・ランの終わりを持つ。`engine.js` の `newGame` が `Run.start`、`endNight` の最後が `Run.nextNight` を呼ぶ。ラン中は `refreshBoard` が何もしない（依頼盤はその夜に選んだ依頼だけ）。
- テスト：`tests/run.test.cjs`（幕と地区マップ）、`tests/reward.test.cjs`（報酬3択と義体の枠）、`tests/boss.test.cjs`（前歴と幕のボス）、`tests/psycho.test.cjs`（サイバーサイコシス・鎮圧班・ラザロ・元部下）。キャンペーン版の章・設備・横取りのテストは、ランを外した状態で今も確かめている。

## キャンペーン版から引き継いだ仕様

以下はキャンペーン版の説明です。判定・交戦・派遣の中身はそのまま使っています。家賃・借金・ローン・設備・評判ランク・依頼盤の入れ替わり・章の進み方は、ローグライク版では上の仕様に置き換わっています。

- 現場3人・支援2人・ネット1人。能力＋技能＋d10で判定。10は追加、1は減算。HP半分未満は判定−2、防具は貫通時に摩耗、HP0は死亡セーブ。
- 歩合は本人に分け前、専属はフィクサーに分け前が入り毎夜手当が必要。仲介料20%。家賃・借金・義体ローン・救急会費・設備維持費を夜ごとに精算。3夜連続赤字で廃業。
- 評判による紹介依頼でランクを上げ、全6章のブラックボックスの物語を進めます。
  - 第1章 引き継ぎ → 第2章 鍵を探す → **分岐**（ミツカネ・ヴェルデ・ハクロウのどれと組むか）→ 第3章 積み荷（3通り）→ 第4章 沈む名前 → 第5章 調整役（3通り）→ 第6章 夜明け。
  - 組んだ社はヒート−30、残りの二社は+10。分岐ごとにメイン依頼の標的・必要なロール・物語が変わり、第4章と第6章にも組んだ社ごとの段落が入ります。分岐を選ぶまで夜は明けません。
  - 第4章のメイン依頼は、章に入ってから2夜たつと依頼盤に出ます（手がかりを洗う期間）。
  - 分岐を入れる前の保存データは、元の筋書きと同じ依頼が並ぶハクロウの分岐として続きます。企業3社のヒート100で防衛戦。
- 派遣中の現場重傷、警報、死亡セーブ生存で最大2回、続行／撤退を選択。敵の攻撃直後に中断でき、続行時に済んだ判定は繰り返しません。撤退は報酬なし・失敗扱い、固定費は通常どおり。2夜依頼は実際の夜ごとに判定。判断待ちは保存・再開できます。
- 屋台街・港湾倉庫・企業区画上層。地区状況は3夜、ニュース17種は1夜。毎夜「噂」が1つ流れ、白蛇会との関係・ヒート・死者・章に応じた噂も混ざります。補正は判定と見積もりで共通。運搬の報酬補正は派遣時に固定されます。
- 依頼は通常18種（ランク1：9、ランク2：6、ランク3：3）。記憶テープの奪還、白蛇会の看板の乗っ取り、逃げたAIの捕獲、差し押さえ義体の奪還、記憶銀行からの人格の引き出しなど。
- 幕間7種：初めての義体、初めての死者、人間性15以下、ランク2、ヒート80、夜12、箱を開けた後。条件を満たした夜明けに一度だけ流れる。結末では、生き残ったランナーのその後が一行ずつ添えられる。
- 白蛇会との関係は−100〜100。+30以上で情報割引・路上候補増、−30以下で敵増援と3夜ごとの嫌がらせ。防犯設備で嫌がらせを防止。
- 隠れ家の設備8種（2,500〜9,000cr、一部は2段階）：訓練室、武器庫、医療室、ネット設備、車庫、情報屋の端末、防犯システム、仮眠室。「装備・設備」タブで購入。維持費は夜明けの見込みにも表示。
- 成長：派遣中の判定に使った技能に経験がたまり、素の技能 n→n+1 は n+4 回で上がる（上限10）。訓練室があれば待機中も本業の技能が伸びる。技能カードの細い線が次の上昇までの進み具合。
- 装備21種（武器・防具・道具を1つずつ、700〜5,000cr）。人間性を削らずに技能や防具を足す。専属はフィクサー、歩合は本人の手持ちで払い、歩合は自分でも買う。入れ替えは半額で下取り。徹甲ライフルはテックなしで装甲兵の弱点を突く。テーザーは過剰な暴力にならず、ICE遮断フードは黒ICEの逆流を半減する。
- 義体31種を6つの部位（神経系・頭脳・感覚と発声・腕と手・体表・内臓）に分け、闇医者で部位ごとに絞り込める。系統ごとに上位モデル（Mk.II・Mk.III）があり、入れると下位モデルと入れ替わって人間性は差の分だけ減る。下位モデルへは戻せない。基本モデルの人間性コストは下げ、上位モデルほど重い。ニューラル防壁は黒ICEと敵ネットランナーの攻撃を無効化、人工心臓は死亡セーブ+2（弐は+3）。どれも肖像に重ねて描かれる。
- 精算の「効いたもの」に、技能・装備・義体・設備が失敗を成功に変えた回数を表示。通信の計算式も補正の出どころ（〈装備+2〉、＋逃げ足 3 など）を分けて表示。ロール技能はこれまでに効いた回数をランナーカードに残す。
- 成功の見込みに、判定ごとの成功率と担当、失敗するときの主な原因を表示。
- 右上の「説明」ボタンで初めての人向けの説明（チュートリアル、凡例、各画面の解説、隠れ家のヒート欄）をまとめて隠せる。設定はブラウザーに保存。
- ランク1の敵はDV17・攻撃16・3d6+2、ランク1依頼の判定DVは+2。初期の2人編成で70〜90%、3人のそろった編成でほぼ確実。
- 装甲兵（テックで弱点攻撃）、敵ネットランナー（ICE攻撃）、狙撃手（知覚で先制阻止）、群れ。情報購入で敵種を開示。
- 雇えるランナーには出自ごとの素性が1行つく。
- まれに資質つきのランナーが現れる（候補1人ごとに、超希少の異常適合3%・希少の適合体質10%・希少の天才肌8%）。異常適合は人間性の上限150で義体の人間性コストが半分、適合体質は上限+30でコスト3/4、天才肌は技能の伸びが早い。資質つきは分け前の希望と手当が高い（1.2〜1.8倍）。ヨルは適合体質。
- 物語つきは5人（カゲロウ・ヨル・ハルカ・シグレ・ミコト）。ヨル・ハルカ・シグレ・ミコトは夜3以降、35%の夜にスカウトへ現れる。専属かつ忠誠70以上で個人依頼。シグレの依頼はクロガネとの関係が下がる。本人参加が必須。成功でロール技能と別の専用技能、失敗は忠誠−30、期限まで受けなければ離脱。発生時に物語を表示。
- クロガネ・ネオンの2人が依頼を横取りし、ランナーを引き抜きます。妨害依頼と関係・横取り・引き抜き状況を表示。
- 保存データが読み込めないときは消さずに残し、タイトルで知らせる（最新のファイルで読み込み直す・保存データを書き出す）。新しく始めるときは直前の保存データを `fixers-cut-save-v1-backup` に1つ残す。画面の描画が止まったときは、白い画面ではなく復旧の画面を出す。GitHub Pagesはファイルを10分キャッシュするため、更新直後は古いファイルが混ざることがある。
- 最後の派遣編成を「いつもの面子」で復元。欠員・重体・療養・派遣中は除外して通知。通信速度4段階と合成効果音（初期オフ）は保存。一括表示・一瞬・動きを減らす設定では音が集中しません。

## 構成

- `js/data.js`：依頼・ロール・義体・装備・物語・章の表。依頼の判定DV、交戦ごとの敵種と敵DV（`C(数, 名前, 敵種, 敵DV)`）、地区はここに書かれた値がそのまま使われます。
- `js/engine.js`：状態、判定、夜の進行、精算、章の進行（条件の種類 `REQS`）。敵の基準値 `RANK_ENEMY` と編成枠 `LANE_MAX` もここ。
- `js/world.js`：地区・ニュース・設備・関係・ライバルなど、夜ごとに変わるルール。静的な表は書き換えません。
- 章は `CHAPTERS` に章のキーで定義し、保存データもキーを持ちます。章を足すときは、`CHAPTERS` に1件足して前の章の `next` をつなぎ、メイン依頼があれば `CAMPAIGN_JOBS` に `campaign: '章のキー'` で足します。表示の番号（`no`）は分岐で同じ番号を共有してかまいません。分岐は、メイン依頼の成功後に出す `choice` と、手を組んだ社で次の章を決める `next: { ally: {...} }` で書きます。番号で章を持っていた古い保存データと、分岐前のキー（`cargo`・`coordinator`）は、読み込み時に変換されます。
- `js/comfort.js`：いつもの面子と効果音。`ui.js` より先に読み込みます。
- `js/art.js`・`js/ui.js`：描画と操作。
