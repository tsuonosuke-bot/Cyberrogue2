# 肖像の絵：仕様と差し替え手順

ランナーの肖像は、このフォルダの絵の上に、ゲームが義体と機械化を重ねて描く仕組みです。今入っているのは仮の絵（SVG）です。同じ名前で本番の絵を置けば差し替わります。

## 必要な絵（35枚）

### ロール×性別（30枚）

ファイル名は `ロール-性別-番号` です。同じ組み合わせのランナーには、2枚のうちどちらかが割り当てられます。

| ロール | 男性 | 女性 | その他 |
|---|---|---|---|
| ソロ | `solo-m-1` `solo-m-2` | `solo-f-1` `solo-f-2` | `solo-x-1` `solo-x-2` |
| ネットランナー | `net-m-1` `net-m-2` | `net-f-1` `net-f-2` | `net-x-1` `net-x-2` |
| テック | `tech-m-1` `tech-m-2` | `tech-f-1` `tech-f-2` | `tech-x-1` `tech-x-2` |
| メドテック | `med-m-1` `med-m-2` | `med-f-1` `med-f-2` | `med-x-1` `med-x-2` |
| ドライバー | `driver-m-1` `driver-m-2` | `driver-f-1` `driver-f-2` | `driver-x-1` `driver-x-2` |

「その他」は、中性的な見た目か、アンドロイド風の見た目です。

ロールは服装で描き分けます。仮の絵もこの描き分けにしてあります。

| ロール | 目印 |
|---|---|
| ソロ | 高い襟の黒いジャケット。襟の裏がピンク |
| ネットランナー | 青いフード |
| テック | 額に上げたゴーグル |
| メドテック | 白衣と、首に下げたマスク |
| ドライバー | ピンクの色付きバイザー |

## 形式

- 正方形。512×512 以上、おすすめは 1024×1024
- PNG か WebP。1枚 1MB 以下を目安にする（公開ページの上限は1ファイル15MB）
- 背景込みの絵にする（透過しなくてよい）

## 構図

義体は決まった位置に重ねて描かれます。次の位置に合わせて描くと、そのままずれずに重なります。位置は左上を0、右下を100とした割合です。

| 部位 | 位置 | 重なる義体 |
|---|---|---|
| 顔の中心 | 横50・縦38（顔の幅は全体の約30%） | 機械化の広がり |
| 画面の左の目／右の目 | 43,40 ／ 57,40 | 右の目に鷹の目オプティクス |
| 額 | 50,25 | 解析コプロセッサ |
| 右のこめかみ | 63,31 | シナプス加速器 |
| 左の耳 | 34,41 | 音響センサー |
| 左の頬 | 40,47 | 皮下装甲板 |
| 首・のど | 50,60 ／ 50,63 | 高速ニューラルジャック、声帯変調器 |
| 首の左 | 45,57 | 反射ステアリング、痛覚遮断 |
| 胸の右 | 64,86 | 皮下メディキット |
| 左下（肩から腕） | 8〜32, 74〜100 | 鉄骨アーム |
| 右下（手） | 70〜90, 84〜100 | 工具指 |

- バストアップで、正面かやや斜めを向いた構図にする
- **義体は描かない。** ゲームが重ねて描きます。ヨルは最初から鉄骨アームと鷹の目を入れていますが、絵には描かないでください
- 文字やロゴは入れない

位置が合わない絵でも使えます。その場合は下の「ずれたとき」の手順で、絵ごとに位置を書きます。

## 絵柄

企画書の「2色刷りのリソグラフ」と、ゲームの「夜のネオン」に合わせます。

- 暗い紺の背景に、細かい網点
- 色はピンク `#ff4f9a` と青 `#6f9dff` を基調にする。縁にネオンの光を入れる
- 33枚で絵柄を揃える。画像生成を使う場合は、同じ指示文の型と同じ参照画像を使う

### 画像生成の指示文の例

```
Bust portrait of a cyberpunk mercenary, woman, high-collar black jacket with pink lining,
facing the viewer, face centered slightly above the middle, shoulders at the bottom edge,
dark navy background with subtle halftone dots, two-color risograph print style,
neon pink (#ff4f9a) and electric blue (#6f9dff) rim light,
no cybernetic implants, no text, square 1:1
```

ロールと性別の部分（`mercenary, woman, high-collar black jacket ...`）だけを入れ替えて使います。画像生成サービスを使う場合は、そのサービスの利用規約で、ゲームへの利用が認められているかを確認してください。

## 差し替えの手順

1. 絵をこのフォルダに、同じ名前で置く（例：`solo-f-1.png`）
2. 拡張子を変えた場合は、`js/art.js` を直す
   - 全部を PNG にしたなら、`PORTRAIT_EXT` を `'png'` にする
   - 一部だけなら、`PORTRAIT_FILES` に `{ 'solo-f-1': 'solo-f-1.png' }` のように書く
3. ローカルサーバーを起動して、`tools/portraits.html` を開く。義体がずれていないかを確かめる
   ```
   python3 -m http.server 8765 --directory /Users/mk_0311/Cyberpunk
   ```
   開くページ：`http://localhost:8765/tools/portraits.html`
4. Claude に公開ページの更新を頼む

### ずれたとき

`tools/portraits.html` で絵をクリックすると、その位置の座標が出ます。その値を `js/art.js` の `PORTRAIT_ANCHOR_OVERRIDES` に、絵ごとに書きます。

```js
const PORTRAIT_ANCHOR_OVERRIDES = {
  'solo-f-1': { eyeL: [41, 38], eyeR: [58, 38], head: [50, 36, 16, 20] },
};
```

書ける項目は `PORTRAIT_ANCHORS` と同じです。書かなかった項目は既定の位置になります。

## 仮の絵を作り直す

```
node tools/make-placeholders.js
```

仮の絵（中に `<!-- placeholder -->` がある SVG）だけを書き直します。同じ名前の SVG を本番の絵に置き換えていれば、それは上書きしません。
