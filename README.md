# Fixer's Cut ローグライク版

ヨミハマの新人フィクサーとして、何度も負けながら「ラン」を繰り返すブラウザーゲームです。キャンペーン版 Fixer's Cut（`tsuonosuke-bot/Cyberpunk`）から複製し、ローグライクに作り替えています。キャンペーン版のコードはこのリポジトリから消しました（元の長編は別のリポジトリにあります）。外部サーバーやビルドは不要です。UTF-8の静的HTTPサーバーで `index.html` を開いてください。保存先はブラウザーのlocalStorageです。

作り直しの方針は企画書「Fixer's Cut ローグライク 改善企画書」（段階0・A・B1・C・B2・D・E）にまとめています。企画書の段階（0・A・B1・C・B2・D・E）はひととおりできています。

## 今のルール

- 1ランは3幕・30夜（第1幕 屋台街／第2幕 港湾倉庫／第3幕 企業区画上層）。各幕は10夜で、10夜目が大仕事。
- 地区マップ：幕の始めに10夜分の地図を全部見せる。1〜9夜目は行き先が2〜4つ（1夜目は3つ、9夜目は2つ）で、行き先どうしは線でつながっている。昨夜選んだ行き先から線がつながった先にしか進めない（2夜依頼で飛んだ夜は2つ先までたどる）。毎夜、依頼か危ない依頼が1つはあり、4夜目・8夜目・9夜目には隠れ家か闇医者がある。9夜目は大仕事の前の準備の夜で、8夜目のどこからでも9夜目のどの行き先にも行ける。8夜目と9夜目の依頼は1夜で終わるものだけ。同じ夜に同じ行き先は並ばない（依頼だけは2つまで）。
- 依頼のルート：依頼が出るたびに、判定のDV（±2）と敵の数（±1）・種類を少し変える。ICEの位置・目標の数・必須ロールは変えない。3分の1ほどの依頼には3本目のルート（強行：隠密と説得を交戦に／裏道：交戦を隠密に）が加わる。依頼の画面では、ルートごとに「隠密●○○ 交戦●●○ ネット○○○」の性格を出し、隊にいちばん多い型に合う道に「おすすめ」を付ける。
- 依頼の型紙は28件（ランク1：9、ランク2：10、ランク3：9）。同じ幕ではなるべく同じ依頼を出さない。
- 毎夜、今夜選べる行き先をタップ1回で出発する（地図の光っている行き先か、その上の詳しい一覧から）。依頼なら編成画面が開く。地図の依頼には必須ロールの点（青：隊にいる／ピンク：いない）がつく。
  - 依頼：その幕と同じランクの依頼1件。危ない依頼：1つ上のランク（第3幕はランク3のDV+2、報酬1.3倍）。
  - 闇医者・古物屋・路地裏：その夜だけ画面が開く。隠れ家：全員のHPが戻り、人間性+5。事件：選択肢つきの出来事。
  - 2夜依頼は次の夜も使う。大仕事は一発勝負で、失敗する（送り出さない）とランは終わる。1ランは必ず30夜で終わる。
- 敵の強さ：依頼のランクの基準値（`RANK_ENEMY`。第1幕DV17・攻撃16、第2幕DV18・攻撃16、第3幕DV19・攻撃18）に、`Run.threat` を足す。幕のなかで夜が進むと+0→+1→+2（4夜目から+1、7夜目から+2）、大仕事の夜はさらに `BOSS_THREAT`（第1幕+0、第2幕・第3幕+4）。幕ごとの差は `ACT_THREAT`（第1幕0、第2幕0、第3幕+3）。
- 幕のボス（`RUN_BOSSES`）：第1幕「電気屋」（耐久2）、第2幕「カナメ」（耐久3、護衛は狙撃手）、第3幕は組んだ社で変わる。ミツカネ「鋼の番犬」（耐久5）、ヴェルデ「被検体」（耐久6、説得DV22で正気に戻せる）、ハクロウ「保守主任」（黒ICE3層DV22・23・24、現場から電子DV24で回線を切る）。倒すとボスの品が報酬に混ざる。
- 最初の隊：ランダムな3人。ネットランナー1人と、戦える人（ソロかドライバー）1人を必ず含む。最初の行き先を選ぶまで、1回だけ引き直せる。初めてのランだけは決まった隊（ジロウ・サエ・ネットランナー）。寄せ集めは3人のロールを自分で選ぶ。
- 前歴：ラン中ずっと効く利点と弱み。元ソロ（交戦の1ラウンド目、ソロの射撃+1／ICE判定−2）、元ネットランナー（各幕のはじめに情報券+1／説得−1）、闇医者のツテ（義体の人間性コスト−1／運転と逃走−1）、企業の元社員（組む社を始めに決める・その社のヒート−15／残りの2社+10）、白蛇会の身内（白蛇会との関係+30／最初の隊・候補が義体を入れていて人間性が低い）、寄せ集め（ロールを選べる／初期資金1,500cr・報酬2択）。後の3つは段階Dで信用で解放する。
- 隊：上限4人。臨時雇いは数えない。
  - 路地裏：夜を使う。契約金なしで3人から雇え、資質の出やすさ2倍。
  - 顔見せ（隊の画面）：毎晩2人。夜を使わないが、契約金（第1幕1,500cr・第2幕3,000cr・第3幕5,000cr）。
  - 隊がいっぱいなら、雇う画面で入れ替える人を選ぶ。外した人の義体と装備は戻らない。
  - 臨時雇い：依頼の必須ロールが隊にいないとき、編成画面からその依頼1回だけ人を借りる。費用は顔見せの半額で、精算のときに後払い。大仕事では各幕1回無料。精算が終わると抜ける。
  - 隊員が死ぬ・引き渡す・脱走すると、次の報酬に補充のランナーが必ず1人入る（自分で外したときは除く）。
- お金：初期3,000cr。毎夜の固定費（ランニングコスト）はない。依頼の報酬は型紙の6割で、全額フィクサーに入る。3夜続けてマイナスで廃業。
- 型（`TYPES`）：義体・装備・資質はどれも型を1つか2つ持つ（隠密・火力・電脳・義体狂い・持久）。依頼に送り出した人の型を数え、2つ・4つ・6つで隊全体に効果が付く（engine.js の `typeOn`）。
  - 隠密：判定+1／隠密に成功すると次の交戦の敵−1／依頼ごとに1回、交戦を丸ごと避ける
  - 火力：1ラウンド目の射撃+1／敵を倒した人がそのラウンドにもう一度撃つ／待ち伏せされず先に撃つ
  - 電脳：ICE判定+2／ネットを抜けると次の交戦の敵のDVと攻撃−1／黒ICEの逆流を受けない
  - 義体狂い：人間性30以下の人の射撃+1／回避+1／暴走中の人が倒れない
  - 持久：交戦のあと全員HP+5・重傷の−2を受けない／交戦を4ラウンドまで粘れる・死亡セーブ+2／依頼ごとに1回、死ぬはずの人が動けないだけで済む
  - 大仕事のボスは型を1つ受け付けない（電気屋：電脳、カナメ：火力、鋼の番犬：隠密、被検体：義体狂い、保守主任：持久）。
  - 前歴は型の種の装備を1つ持って始まる（元ソロ：重拳銃、元ネット：デッキ、闇医者のツテ：防弾ジャケット、企業の元社員：偽造ID。白蛇会の身内は義体で始まる）。
- コネ（`CONNECTIONS`、14種）：ラン中ずっと効く特殊効果。値引き・判定の補正・保険・報酬の増額など。大仕事で出るコネは強いかわりに弱みを持つ（壊れた良心・血の誓い・企業の後ろ盾・鉄の規律）。
- 報酬3択：依頼に成功すると3つの枠から1つ。1つ目は隊にいちばん多い型の品、2つ目は別の型の品（ボスを倒した大仕事ではボスの品）、3つ目はコネか型のないもの（ランナーかcr）。危ない依頼と大仕事の3つ目は必ずコネ、普通の依頼は3割。危ない依頼・2夜依頼・大仕事の後は品のどちらかが希少。欠員の後は3つ目にランナー。取らなければ500cr。カードには取ったあとの型の数（例：火力 3→4）を出す。
- 義体の枠：神経系・頭脳・感覚と発声・腕と手・内臓が2つずつ、体表が1つ。同じ系統の上位モデルは枠を使わない。外した義体と削った人間性は戻らない。
- サイバーサイコシス（交戦の始めに判定）：
  - 不安定（人間性16〜30）：d10で2以下なら動揺し、その交戦は射撃・回避−2。交戦が終わるたびに人間性−1。
  - 兆候（1〜15）：d10が (16−人間性)÷4 の切り上げ以下なら暴走。射撃+2で2回撃つ。3体倒すと市警の鎮圧班が来る（引き渡す・かばう）。
  - 喪失（0）：隊から消え、5夜のあいだ地区マップに「元部下」が出る。
  - 編成画面に「動揺20%」「暴走○%」を出す。人間性16〜18で夜が明けると、様子がおかしいと知らせる。
- ラザロ：闇医者で1人ずつ加入する。加入料はその場で1回だけで、基本は600cr、武装回収（第2幕から）は2,000cr（基本からは差額）。やめても戻らない。
- ランの終わり：廃業・全滅・大仕事に2度失敗・クリア。負けたときは結果画面に「負けた理由」（終わり方、最後に失敗した依頼と理由、最後の数夜で失った人）を出す。
- 積み上げ（`js/meta.js`）：ランのたびに「信用」がたまる（生き延びた夜1点、大仕事を越えると第1幕10・第2幕20・第3幕30、クリア50、初めてのことは1回きりの追加）。タイトルと結果画面の「隠れ家の改装」で使う。一通りそろうのは25〜30ラン。
  - 部屋（5つ×3段）：診療室（出発時の人間性+10／各幕に1回、死ぬはずの人が重傷で済む／隠れ家の人間性の回復+5）、武器庫（装備を持ち込む）、端末室（情報券／各幕の情報券+1／情報が半額・大仕事の夜の敵−2・ボスの耐久−1）、宿舎（顔見せの候補+1／引き直し+1／契約金−30%）、金庫（初期資金+700crずつ）。
  - 協力者（3人）：解放すると、各幕の5夜目にその人の地点が出る（闇市の顔役：多い型の品を2つから1つ、運び屋：全員のHPと1,500cr、元警官：全社のヒート−20と手配の取り消し）。
  - 出発前の準備（4つ）：解放したものから、ランの始めに1つ選ぶ（初期資金+1,000cr／基本の義体1つ／弱みのないコネ1つ／希少な資質1つ）。
  - 解放：後の3つの前歴（企業の元社員・白蛇会の身内・寄せ集め）と、型ごとの強い品2つずつ（解放するまで報酬・古物屋・闇医者に出ない）。
  - 前歴の熟練：その前歴で3回遊ぶと2段（型の種の品をもう1つ）、8回で3段（前歴の弱みが消える）。
  - 記念碑（帰ってこなかった者をランをまたいで残す）、伝説（クリアしたランでいちばん倒した生き残りが、以後の路地裏にまれに現れる）、物語の断片（大仕事のボスを初めて倒すたびに1つ。5つそろうと、クリアの結末に一節が加わる）。
- 通信：送り出した依頼は最後まで判定する（続行／撤退の判断はない。止まるのは鎮圧班が来たときだけ）。通信はいつもは結果（成功・失敗・会心・大失敗）と描写・セリフを出し、ダイスの計算は「ダイスを見る」で開く（設定に残る）。
- 危険度（`Meta.DANGER`）：クリアするたびに次の段が開く（最大5）。各段は前の段の縛りを引き継ぎ、稼ぐ信用は1段ごとに+10%。1：大仕事のボスが送り出した人にいちばん多い型にも耐性を持つ／2：地区マップは2夜先までしか見えない／3：隠れ家で回復できるのはいちばん傷の深い2人まで／4：報酬の3択の1枠が3割ほどの確率で空く／5：大仕事のボスの耐久+1。前歴の画面で選ぶ。
- 難しさの目安（ボットの慎重な方針、前歴ごとに300回）：積み上げなしでクリア率およそ9%、積み上げを全部そろえておよそ36%、全部そろえて危険度5でおよそ20%。撤退と大仕事の挑み直しをなくし、敵と報酬を締める前は、それぞれ17%・48%・30%だった。ボットは人より下手なので、人のクリア率はこれより高い。
- 保存：ランは `fixers-cut-run-v2`（1幕10夜にしたときに上げた。前の版の遊びかけのランは読まない）、ラン数と最高到達は `fixers-cut-meta-v1`。

判定・交戦・派遣の中身（現場3人・支援2人・ネット1人、能力＋技能＋d10、2夜依頼、地区とニュース、白蛇会との関係、装備と義体、資質、物語つきランナー、幕間）はキャンペーン版から引き継いでいます。

## 構成

- `js/data.js`：依頼・ロール・義体・装備・ボス・大仕事・物語の表。
- `js/engine.js`：状態、判定、交戦、夜の進行、精算。`RANK_ENEMY`・`ROSTER_MAX`・`LANE_MAX` もここ。
- `js/meta.js`：積み上げ（信用・部屋・協力者・準備・解放・熟練・記念碑・伝説・断片）。
- `js/run.js`：幕・地区マップ（`genMap`・`link`・`reachable`・`mapView`）・行き先・前歴・最初の隊・顔見せ・臨時雇い・報酬3択・元部下・ランの終わり。敵の上乗せ `ACT_THREAT`・`BOSS_THREAT` もここ。
- `js/world.js`：地区・ニュース・噂・白蛇会との関係。
- `js/comfort.js`：いつもの面子と効果音。`js/art.js`・`js/ui.js`：描画と操作。
- `js/flavor.js`：通信の描写とセリフ（技能×結果の描写、ロールごとのセリフ、人間性が低い人の口ぶり）。どの文を出すかは行の中身から決め、乱数は使わない。

## 検証

Node.js 24で実行します。依存パッケージはありません。

```bash
for f in tests/*.test.cjs; do node --test "$f"; done
```

バランスはボットで測ります。ランを最後まで自動で遊び、幕ごとの成功率・幕を越えた割合・死者・送れなかった夜・失敗の理由をまとめます。

```bash
node tools/bot.cjs --bg all --runs 500
```

`--policy careful,chrome,shopper,random`（慎重・義体を積む・古物屋を使う・行き先だけランダム）、`--policy stealth,fire,net,chrome,endure`（その型を優先して集める）、`--ally mitsukane|verde|hakurou`（組む社を固定）、`--meta full`（積み上げを全部そろえた状態）、`--danger 1〜5`（危険度）、`--json`（失敗の理由なども出す）が使えます。500回で50%付近なら誤差はおよそ±4ポイントです。

`tools/smoke.html` は購入と警報を試すローカル確認画面です。
